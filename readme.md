# Kineta site 

File  uploading and downloading social website I built this website once i learnt how to make backend website following Alex edwards book **let's Go** . great book . that book built a project like pastebin . but learning and understanding that book help me built my own website which is somehow useful . 

## what this website do

- it Allows you to post a file or article 

- it Allows other people to download the files however , there is limit to download file a person can download a file 5 times and then wait for 12 hours and its counter will be set to 0 in db

- user must activate his account to upload , user can activate his account by confirming email after signup 

- it allows people to comments on post & rate the post 

- and full text search
